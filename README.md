# wewln — клавиатура для iPhone

Проект первой версии. Это исходники, НЕ готовый IPA. Требуется сборка на macOS через GitHub Actions. Сборка Xcode и работа на реальном iPhone не проверены в среде автора этого архива: здесь нет macOS/Xcode. Автоматические тесты Swift включены в сборку.

## Что делает

Отдельная русская клавиатура в переключателе 🌐. Вводишь «привет как дела», получаешь «п р и в е т   к а к   д е л а». Между буквами и цифрами один обычный пробел, кнопка пробела вставляет три пробела. Есть ё, ъ, заглавные буквы (на одно нажатие), цифры, знаки, удаление и новая строка. Клавиша удаления убирает букву вместе с её межбуквенным пробелом или тройной пробел целиком.

Не изменяет системную русскую клавиатуру и не преобразует уже вставленный текст. Это базовая версия без автокоррекции, свайпов и удержания удаления. Работает по доступному контексту слева от курсора: если приложение не передаёт контекст, разделитель перед новой буквой может не добавиться. В паролях, телефонных полях и приложениях, запрещающих сторонние клавиатуры, iOS использует системную клавиатуру.

## 1. Получи IPA на Windows через GitHub

Нужен аккаунт GitHub. Apple ID на GitHub не нужен — сборка без подписи.

1. Распакуй архив на ноутбуке.
2. На https://github.com/new создай пустой репозиторий `wewln-keyboard`. Можно Private. У закрытых репозиториев сборки расходуют включённые минуты Actions; перед включением платного использования проверь тариф. Не включай платные расходы ради этой инструкции.
3. Нажми `uploading an existing file` (или Add file → Upload files). Перетащи **содержимое** распакованной папки в корень репозитория: `App`, `Keyboard`, `Tests`, `project.yml`, `README.md`. Не загружай сам ZIP и не создавай лишнюю внешнюю папку.
4. Убедись, что файл сборки находится именно по пути `.github/workflows/build.yml`. Если папка `.github` не загрузилась, нажми Add file → Create new file, в имени укажи `.github/workflows/build.yml`, открой локальный файл `BUILD-WORKFLOW.txt` в Блокноте и скопируй его текст в редактор GitHub. Сохрани через Commit changes. `BUILD-WORKFLOW.txt` — только копия для удобства, он сам ничего не запускает.
5. Открой вкладку Actions → Build wewln → Run workflow → Run workflow.
6. Дождись зелёного результата. Внизу завершённого запуска, в Artifacts, скачай `wewln-IPA`.
7. Распакуй скачанный ZIP: внутри будет `wewln-unsigned.ipa`. Он пока не подписан. Нажатие на него в Safari не установит клавиатуру.

Если запуск красный, открой упавший шаг и сохрани текст ошибки. Не пытайся ставить незавершённый файл. Сборка требует доступности GitHub Actions и macOS runner. Внутри workflow нет запросов Apple ID, пароля или ключей подписи.

## 2. Поставь AltStore Classic с Windows

Официальная инструкция — главный источник для актуальных шагов:
https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows

1. Скачай AltServer только с https://altstore.io/ — нужен **Classic**, не PAL.
2. Следуй официальной инструкции для установки iTunes и iCloud. Она рекомендует версии от Apple, а не Microsoft Store; ссылки и альтернативы есть в инструкции.
3. Подключи разблокированный iPhone кабелем, подтверди «Доверять этому компьютеру».
4. Открой iTunes, войди в учётную запись, включи синхронизацию iPhone по Wi-Fi.
5. Запусти AltServer. Через его значок в области уведомлений Windows выбери Install AltStore → свой iPhone.
6. Вход в Apple Account выполняй только в официальном AltServer/AltStore. **Не отправляй пароль, код 2FA или ключи в чат и не добавляй их в GitHub.** Подписывание требует авторизации Apple, оценку доверия к стороннему установщику принимаешь ты.
7. На iPhone: Настройки → Основные → VPN и управление устройством (название может отличаться) → твой профиль разработчика → Доверять.
8. На iOS 16+: Настройки → Конфиденциальность и безопасность → Режим разработчика. Выполни предложенную перезагрузку и подтверждение. Пункт может появиться только после попытки установки.

## 3. Установи именно клавиатуру

1. Передай `wewln-unsigned.ipa` в приложение «Файлы» на iPhone, например через iCloud Drive.
2. Оставь AltServer работающим на ноутбуке; устройства должны находиться в одной локальной сети, либо используй кабель.
3. Открой AltStore → My Apps → + → выбери IPA.
4. **Если AltStore спрашивает про App Extensions, выбери Keep App Extensions / сохранить расширения.** Удаление расширений удалит саму клавиатуру. Для приложения и клавиатуры нужны отдельные App IDs, поэтому не отключай расширение ради экономии лимита.
5. Дождись установки и открой приложение wewln.
6. Настройки → Основные → Клавиатура → Клавиатуры → Новые клавиатуры → wewln. Если видишь промежуточный список расширений, включи wewln в нём.
7. **«Полный доступ» не включай — для этой клавиатуры он не нужен.**
8. Открой «Заметки», удерживай 🌐, выбери wewln и набери «привет как дела».

Это установка приложения с расширением, а не добавление нового системного языка. Имя wewln задаётся приложению и расширению; точное отображение подписи меню зависит от iOS.

## Поддержание установки

С бесплатной подписью срок — 7 дней. Обновляй через AltStore → My Apps → Refresh All заранее, пока доступен AltServer. Можно использовать автоматическое обновление, но проверяй дату истечения. Обычно допускается 3 активных приложения с бесплатной учётной записью (AltStore занимает одно место), до 10 App IDs за период; расширения тоже расходуют App IDs. Настройка обновления: https://faq.altstore.io/altstore-classic/your-altstore

## Приватность

В исходниках нет сетевых запросов, аналитики, сохранения текста, сторонних SDK и App Groups. RequestsOpenAccess=false. Набранный текст передаётся в поле приложения через стандартный интерфейс клавиатуры. Приложение, в которое ты печатаешь, по-прежнему получает введённый текст. GitHub получает загруженные исходники и логи сборки, не текст переписки.

## Проверка на телефоне после сборки

- В меню 🌐 появилась wewln; можно переключиться обратно.
- «привет как дела» → «п р и в е т   к а к   д е л а».
- Работают ё/ъ, ⇧, 123, удаление, новая строка и выделение текста.
- Нет наложений в портретном и горизонтальном режиме; проверь светлую и тёмную тему.
- В поле пароля переключается системная клавиатура (это нормально).
- Полный доступ выключен.
