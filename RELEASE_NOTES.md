# wewln — клавиатура для iPhone

Русская клавиатура: один пробел между буквами и три между словами.

В этой сборке добавлена иконка: белая W и три голубые точки на тёмном фоне.

## Скачать
- **wewln-unsigned.ipa** — приложение с расширением клавиатуры и иконкой.
- **wewln-icon.png** — иконка 1024 × 1024 отдельно.
- **SHA256SUMS.txt** — контрольная сумма IPA.

## Установка
IPA **не подписан**. Нужна подпись для своего устройства, например через AltStore Classic. Публикация в Releases не устраняет ошибки авторизации Apple в установщиках.

При подписывании сохраняйте расширение **WewlnKeyboard** (не включайте Remove App Extensions).
После установки: Настройки → Основные → Клавиатура → Клавиатуры → Новые клавиатуры → wewln. Полный доступ не нужен.

Минимальная версия — iOS 16.0. С бесплатной подписью требуется обновление каждые 7 дней. Сборка и тесты логики выполняются в GitHub Actions; работа интерфейса на реальном iPhone не проверена.
